# 📊 Cancer Prediction using Cross Validation

## 📌 Project Description
This project predicts cancer diagnosis using machine learning models evaluated through Cross Validation techniques. Cross Validation ensures the model’s performance is reliable and not dependent on a single train-test split, improving generalization and robustness.

The application is deployed as an interactive Streamlit web application where users can input medical features and obtain real-time cancer prediction results.

---

## 🎯 Objective
The objective of this project is to build a reliable cancer prediction model and validate its performance using k-fold cross validation to achieve consistent and unbiased evaluation.

---

## 🧠 Machine Learning & Validation Technique
- Machine Learning Algorithm: Classification Model (e.g., Logistic Regression / Random Forest / SVM)
- Evaluation Technique: K-Fold Cross Validation
- Type: Supervised Learning (Classification)

Cross Validation divides the dataset into multiple folds, training and testing the model repeatedly to obtain a stable and accurate performance score.

---

## 📊 Dataset Information
The dataset contains medical diagnostic attributes such as:

- Mean Radius
- Mean Texture
- Mean Perimeter
- Mean Area
- Smoothness
- Compactness
- Concavity
- Symmetry
- Fractal Dimension

Target Variable:
- Diagnosis (Benign / Malignant)
